🚀 Arkiv CDN - Public File Viewer

Retrieve and view files stored on Arkiv Network by their UUID

Usage Examples

1. Direct Image Embedding:
<img src="http://localhost:3000/data/YOUR-UUID" />
2. Video Player:
<video controls> <source src="http://localhost:3000/data/YOUR-UUID" type="video/mp4"> </video>
3. Download Link:
<a href="http://localhost:3000/data/YOUR-UUID" download>Download File</a>
4. JavaScript Fetch:
const response = await fetch('http://localhost:3000/data/YOUR-UUID'); const blob = await response.blob(); const url = URL.createObjectURL(blob); // Use url in img.src, video.src, etc.
